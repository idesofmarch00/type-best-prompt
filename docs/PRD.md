# 🏎️ PROMPT BLITZ - Product Requirements Document (PRD)

## 1. Project Overview & Strategic Vision
**Prompt Blitz** is a high-performance, real-time multiplayer developer training platform. 

As software development shifts from raw code execution to multi-agent intent management, the ultimate professional bottleneck becomes communication clarity. Prompt Blitz gamifies syntactical accuracy, DevOps infrastructure muscle memory, and advanced single-turn reasoning boundaries to train users to become deterministic AI-agent conductors.

## 2. Core Philosophy & Paradigm Shift
In an era where autonomous agents can execute rapidly, single freelancers and professionals must orchestrate agent clusters. However, agents fail with ambiguous inputs. Prompt Blitz trains cognitive deconstruction: taking a multi-turn, multi-variable scenario and collapsing it into a single, structured prompt under pressure.

## 3. Platform Game Modes
The platform will feature an interactive TypeRacer-style visual interface (F1 racing progression bars) with real-time multiplayer capabilities across four distinct game modes.

### 3.1 ⚡ Prompt Strategy Mode (AI Arena Duel)
- **Workflow**: Players receive a highly ambiguous or broken development requirement. They have a strict countdown (e.g., 30-40 seconds) to type a structured prompt bounding the AI's execution.
- **Evaluation**: The backend evaluates the prompt using AI inference to test if it yields correctly structured outputs or code that passes unit tests.

### 3.2 💻 Code Syntax Injection Mode (The No-Typo Suite)
- **Workflow**: A lightning-fast typing race using real-world algorithmic paradigms and core engineering components.
- **Specialty Logic**: The input layout strictly tracks complex control blocks (`{`, `}`, `=>`, `\t`) and special operators without breaking client-side UI rendering.

### 3.3 ⌨️ DevOps & CLI Muscle Memory (Infrastructure Drills)
- **Workflow**: Text injection designed to lock complex, operational syntax into permanent muscle memory.
- **Drill Scenarios**: Commands like `docker system prune --volumes -a`, `hasura metadata apply`, and `./gradlew clean build --no-daemon`.

### 3.4 🩺 Reasoning & Deconstruction Mode (High-Stakes Domain Analysis)
- **Workflow**: Targeted at complex domains (SAT, IIT-JEE, NEET-MBBS, clinical analysis). Players receive massive, multi-variable textual data.
- **Challenge**: The player must type a single prompt that forces the AI (e.g., DeepSeek-R1 / OpenAI o1) to reason through a Chain-of-Thought (CoT) pipeline, verifying dependencies before producing a factual output.
- **Evaluation Engine**: Inspects for both a "Thinking Target" (did the prompt force correct reasoning paths) and an "Assertion Target" (did the final answer match the ground-truth dataset).

## 4. Key Features & Requirements
- **Real-time Multiplayer PvP**: Shareable room links, instantaneous synchronization, and visual F1 racing indicators.
- **Authentication**: Single-click Google OAuth 2.0 login.
- **Leaderboards & Analytics**: Global and local multiplayer rankings tracking WPM, prompt accuracy, and reasoning scores.
- **Bring Your Own Key (BYOK)**: Configuration panel allowing advanced users to plug in custom enterprise API tokens for LLM inference.
